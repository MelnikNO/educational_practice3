### Этап 1

**Тема исследования:**  
Оптимизация алгоритмов маршрутизации в динамических mesh-сетях с использованием методов машинного обучения

**Научная проблема:**  
В динамических беспроводных mesh-сетях (WMN) традиционные протоколы маршрутизации (OLSR, BATMAN, Babel) не адаптируются в реальном времени к изменениям топологии, загрузке каналов и качеству связи. Это приводит к росту задержек, потерям пакетов и неэффективному использованию пропускной способности. Отсутствует универсальный метод построения маршрутов, учитывающий одновременно несколько метрик (RSSI, загрузку узла, число переходов) без ручной настройки весов.

### Этап 2

**Цель исследования:**  
Разработать и экспериментально оценить адаптивный алгоритм маршрутизации для динамических mesh-сетей на основе обучения с подкреплением (Q-learning).

**Задачи исследования:**

1. Провести аналитический обзор существующих протоколов маршрутизации для mesh-сетей и выявить их ограничения.
2. Разработать математическую модель маршрутизации с учётом динамических метрик качества канала.
3. Спроектировать алгоритм Q-маршрутизации, адаптирующий пути в реальном времени.
4. Реализовать программный прототип в среде симуляции сети (ns-3 или OMNeT++).
5. Провести вычислительные эксперименты для сравнения разработанного алгоритма с классическими протоколами (OLSR, BATMAN) по метрикам: задержка, доставка пакетов, служебный трафик.
6. Оценить эффективность предложенного подхода и сформулировать рекомендации по его применению.

**Гипотеза:**

| Тип методов | Конкретные методы | Обоснование выбора |

### Этап 6

**Актуальность темы.**  
Беспроводные mesh-сети (Wireless Mesh Networks, WMN) активно применяются в системах «умного города», промышленной автоматизации, организациях временных пунктов связи и в условиях отсутствия развитой инфраструктуры. Однако ключевой проблемой остаётся поддержание эффективной маршрутизации в условиях динамически изменяющейся топологии, интерференции и нестабильного качества каналов. Классические протоколы (OLSR, BATMAN, Babel) либо требуют ручной настройки весов, либо не успевают адаптироваться к быстрым изменениям, что приводит к росту задержек и потерям пакетов.  

Современные методы машинного обучения, особенно обучение с подкреплением, позволяют агенту (сетевому узлу) обучаться оптимальной стратегии маршрутизации непосредственно во время работы сети без явного задания модели изменений. Это открывает возможность создания самоадаптирующихся протоколов нового поколения.

**Научная проблема.**  
В существующих подходах к маршрутизации в динамических mesh-сетях не решена задача одновременного учёта нескольких конфликтующих метрик (задержка, надёжность, загрузка узла) в реальном времени без ручного определения весов. Отсутствуют сравнительные количественные оценки эффективности Q-обучения относительно промышленных протоколов в контролируемых, воспроизводимых сценариях.

**Цель исследования.**  
Разработать и экспериментально оценить адаптивный алгоритм маршрутизации для динамических mesh-сетей на основе обучения с подкреплением (Q-learning).

**Задачи исследования.**  
1. Провести аналитический обзор существующих протоколов маршрутизации и методов ML для WMN.  
2. Разработать математическую модель маршрутизации с Q-обучением.  
3. Реализовать прототип алгоритма в среде симуляции ns-3.  
4. Сравнить разработанный алгоритм с OLSR и BATMAN по задержке, PDR и служебному трафику.  
5. Сформулировать рекомендации по применению подхода.

**Гипотеза исследования.**  
Применение Q-learning для маршрутизации в динамической mesh-сети позволяет снизить среднюю задержку на 15–25% и повысить коэффициент доставки пакетов на 10–20% по сравнению с классическими протоколами в сценариях с частым изменением топологии.

**Объект исследования.**  
Процесс маршрутизации пакетов в динамической беспроводной mesh-сети.

**Предмет исследования.**  
Алгоритм маршрутизации на основе Q-learning с функцией вознаграждения, агрегирующей несколько метрик качества канала и загрузки узлов.


**Методы исследования.**  
Теоретические (анализ литературы, математическое моделирование); вычислительные (имитационное моделирование в ns-3, нагрузочное тестирование); статистические (сравнение средних, доверительные интервалы).

**Практическая значимость.**  
Разработанный алгоритм может быть применён в системах автономного управления mesh-сетями для IoT, критических инфраструктур и аварийной связи. Прототип в открытой симуляционной среде может служить основой для дальнейших исследований и внедрения в реальные устройства (OpenWrt, RouterOS).
