### Задание 3

Анализатор текста

**Задача** - создать консольную программу для анализа текста на Python

Консольная программа на Python для анализа текстовых файлов. Выполняет статистический анализ и сохраняет результаты в JSON.

**Выбор методологии и её обоснование**

**Выбранная методология: Каскадная (Waterfall)**

**Обоснование выбора:**

| Критерий | Характеристика проекта | Почему Waterfall |
|----------|--------------------------|--------------------------------|
| Чёткость требований | Требования фиксированы: анализ текста, вывод статистики, экспорт в JSON | Водопадная модель требует полного понимания требований до начала разработки |
| Масштаб проекта | Небольшой (один разработчик, ~300 строк кода) | Легко спланировать все этапы заранее |
| Стабильность требований | Заказчик не меняет требования в процессе | Нет необходимости в частых итерациях |
| Линейность этапов | Чтение -> очистка -> анализ -> вывод — чёткая последовательность | Каждый этап логически вытекает из предыдущего|
| Документирование | Требуется чёткая документация по проекту | Waterfall делает акцент на документации каждого этапа |
| Риски | Низкие (нет интеграций с внешними системами) | Легко предсказать сложности на этапе планирования |

**Постановка задачи**

1. Принимает путь к текстовому файлу через аргумент командной строки
2. Выполняет анализ текста и вычисляет:
   - Общее количество слов
   - Количество уникальных слов
   - Топ-10 самых частотных слов с их частотой
   - Среднюю длину слова
   - Количество предложений
   - Количество символов (с пробелами и без)
   - Предполагаемый язык текста (русский/английский)
3. Выводит форматированный отчёт в консоль
4. Сохраняет результаты анализа в JSON-файл

**Выходные данные:** консольный отчёт + JSON-файл

**Сложность 3: Пустые строки и множественные пробелы**

**Проблема:** Исходный текст мог содержать несколько пробелов подряд, пустые строки, табуляции, что искажало статистику.

**Решение:** Нормализация пробелов через re.sub(r'\s+', ' ', cleaned).strip() — заменяет любые пробельные символы (пробелы, табуляции, переводы строк) на одиночный пробел.

**Сложность 4: Определение границ предложений**

**Проблема:** Аббревиатуры (например, "т.е.", "и т.д.") содержат точки, но не являются концом предложения. Полноценное решение требует NLP-библиотек.

**Решение:** Упрощённый подход с re.split(r'[.!?]+', text). Для учебного проекта этого достаточно, в production потребовалось бы подключение nltk или spacy.

**Сложность 5: Производительность на больших файлах**

**Проблема:** Обработка файлов размером более 100 МБ могла быть медленной при использовании самописных циклов.

**Решение:** Использование эффективных встроенных структур данных:

- Counter() вместо ручного подсчёта через словарь

- Генераторы списков вместо циклов с .append()

- set() для уникальных значений вместо ручной проверки

```
# Медленно (O(n²)):
unique = []
for w in words:
    if w not in unique:
        unique.append(w)

# Быстро (O(n)):
unique_count = len(set(words))
```

**Сложность 6: Определение языка без внешних библиотек**

**Проблема:** Требовалось определить язык текста, но использование тяжелых NLP-библиотек (nltk, spacy) нецелесообразно для мини-проекта.

**Решение:** Эвристический метод — сравнение частоты русских букв (а-яё) и английских букв (a-z).
```
if russian > english * 1.5:
    return "Русский"
elif english > russian * 1.5:
    return "Английский"
```
